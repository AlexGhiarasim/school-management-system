# School Management System

Web application for managing students, teachers, classes and grades,
with JWT authentication and role-based access control.

## Tech stack
- Backend: NestJS (TypeScript), Prisma, MySQL
- Frontend: React (Vite)
- Auth: JWT + RBAC (Admin / Teacher / Student)
- Infrastructure: Docker, Docker Compose, GitHub Actions

## Status
Work in progress. Setup instructions will be added as the project evolves.
